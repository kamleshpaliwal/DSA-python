# Daily DSA in Python

A place to practice data structures and algorithms in Python and track daily progress with Git.

## Layout

- `solutions/` — one Python file per problem

## Naming suggestions

Use descriptive names, for example `two_sum.py` or `binary_search.py`. Add the problem source and date in the file's docstring when useful.

## Daily workflow

```bash
cd ~/Documents/DSA-Python
# Add or edit a solution in solutions/
git add solutions/
git commit -m "Add <problem name> solution"
git push
```

The first push needs a remote repository configured with `git remote add origin <repository-url>`.
